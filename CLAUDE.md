## Project

Arcade Vault: a platform to play games online and compete for the highest score (per README, written in Spanish). It follows a spec-driven workflow (`/spec` and `/spec-impl`) using skills from `Klerith/fernando-skills` (`npx skills@latest add Klerith/fernando-skills`). The codebase is currently a fresh Create Next App scaffold (single commit, only `app/layout.tsx`, `app/page.tsx`, `app/globals.css`).

## Commands

```bash
npm run dev     # next dev
npm run build   # next build
npm run start   # next start
npm run lint    # eslint (flat config in eslint.config.mjs)
```

No test runner is configured.

## Next.js version caveat

This uses Next.js 16.4.2 / React 19.3 with breaking changes versus common training data. Per `AGENTS.md`, read the relevant guide in `node_modules/next/dist/docs/` (`01-app`, `02-pages`, `03-architecture`, `04-community`; start at `index.md`) before writing Next.js code, and heed deprecation notices. `AGENTS.md` is re-added by `next dev`; leave it in place.

## Architecture notes

- App Router only (`app/`). Path alias `@/*` maps to the repo root (not `src/`).
- `next.config.ts` enables `cacheComponents`, `partialPrefetching` and `experimental.agentFeedback`. `cacheComponents` changes caching/dynamic rendering semantics, so check the docs before fetching data or using request APIs in components.
- The root layout types its props with the globally generated `LayoutProps<"/">` helper (no import needed; types come from `.next/types`, generated by `next dev`/`next build`).
- Tailwind CSS v4 is wired through Turbopack: `next.config.ts` adds a `*.css` rule using `@tailwindcss/turbopack`. Styling is configured in CSS (`@import "tailwindcss"` and `@theme inline` in `app/globals.css`), with no `tailwind.config`. Theme colors are CSS variables with a `prefers-color-scheme` dark override.
- Fonts: Geist and Geist Mono via `next/font/google`, exposed as `--font-geist-sans` and `--font-geist-mono`.
